# Open components

These files are the non-core runtime layer. They are published for reference and reuse.

- `core/env.js` — constants, clock parsing, logging
- `core/store.js` — settings and session state
- `core/token.js` — token capture from fetch/XHR/SDK
- `core/toast.js` — top-right notification cards
- `core/reader.js` — reader page state and navigation

Closed-source: task orchestration, quiz plan resolution, level exam automation, auto-level loop, game unlock/rate logic, panel wiring.
